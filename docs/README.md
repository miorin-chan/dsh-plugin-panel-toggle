## 限制与卸载行为

- 打开弹窗时按键保留给弹窗处理；若 profile 禁用了内置「插件」面板，快捷键保持当前页面不变并记录一次警告。
- 返回目标仅记录最近离开的单个非插件面板，不维护完整导航历史；长按重复触发不会反复切换。
- 在 **插件** 中停用即可移除命令与面板订阅；用户在快捷键设置中的自定义绑定会作为覆盖项保留。
